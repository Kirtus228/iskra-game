# Искра: проект «Ракета»

Пиксельный платформер с головоломками: робот №7 по имени Искра собирает ракету в подвале
лаборатории, а затем отправляется на орбитальную станцию «Маяк».

## Играть

Откройте страницу игры: https://kirtus228.github.io/iskra-game/

Управление: ← → или A D — идти, пробел — прыжок; на телефоне — кнопки внизу экрана.

## Что внутри

- Два эпизода: лаборатория и станция «Маяк».
- Три уровня в первом эпизоде и три во втором — с невесомостью и лазерными затворами.
- Пять головоломок: поворотные муфты энергосети, чипы питания и пульт реактора.
- Две концовки на выбор.
- Мастерская: корпуса и окраски робота за болты.
- Выбор уровня и сохранение прогресса.

## Файлы

- `index.html` — разметка страницы
- `style.css` — интерфейс
- `game.js` — вся игра: физика, уровни, головоломки, финалы
- `shop.html` — магазин платных наборов (Космонавт 150 ₽, Инженер 300 ₽, Спасибо в титрах 50 ₽)
- `donate.html` — донаты и условия
- `thanks.html` — список поддержавших

## Платные наборы и промокоды

Платёжный сервис не проводит добровольные пожертвования, поэтому продаём конкретные
цифровые наборы: у каждого есть состав, цена и выдача промокодом.

Коды выпускаются генератором:

```
node tools/gen-promo-codes.js K 5   # Космонавт, 5 штук
node tools/gen-promo-codes.js I 3   # Инженер
node tools/gen-promo-codes.js P 1   # Спасибо в титрах
```

Каждая выдача дописывается в `tools/promo-codes.txt` — это журнал продаж.
Формат кода: `ISKRA-K-7K3M-9Q2F`. Проверка офлайн: код несёт контрольную сумму от
секрета из `game.js`, поэтому случайный набор символов не пройдёт. Повторная активация
одного кода на устройстве заблокирована (`usedCodes` в сохранении). Секрет лежит в
`game.js`, то есть при желании его можно вытащить — для наборов за 150–300 ₽ это
приемлемый компромисс; при росте продаж нужен серверный учёт кодов.

Покупатель вводит код в меню игры → «Ввести промокод». Наборы дают только внешний вид
робота и болтики, на прохождение не влияют.

## Как обновить игру

Заменить файлы в репозитории — сайт пересобирается автоматически через минуту.
Деплой из этой папки: `node tools/update-gh-files.js` (файлы `index.html`, `style.css`,
`game.js`, `donate.html`, `shop.html`, `thanks.html`, `README.md`).
