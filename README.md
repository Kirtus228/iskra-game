# Искра: проект «Ракета»

Пиксельный платформер с головоломками: робот №7 по имени Искра собирает ракету в подвале
лаборатории, а затем отправляется на орбитальную станцию «Маяк».

## Играть

Откройте страницу игры: https://kirtus228.github.io/iskra-game/

Управление: ← → или A D — идти, пробел — прыжок; на телефоне — экранные кнопки.

## Что внутри

- Два эпизода: лаборатория и станция «Маяк».
- Три уровня в первом эпизоде и три во втором, с невесомостью и лазерными затворами.
- Пять головоломок: поворотные муфты энергосети, чипы питания и пульт реактора.
- Две концовки на выбор.
- Мастерская: корпуса и окраски робота за болты.
- Выбор уровня и сохранение прогресса.

## Файлы

- `index.html` — разметка и подключение Yandex Games SDK
- `style.css` — интерфейс
- `game.js` — вся игра: физика, уровни, головоломки, финалы
